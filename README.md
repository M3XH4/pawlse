# 🐾 PAWLSE  
### AI-Assisted Stray Animal Welfare Management and Engagement System

PAWLSE is a unified web-based platform designed to support stray animal welfare operations for **Iligan Stray Feeders**. The system centralizes rescue coordination, AI-assisted animal identification, adoption management, volunteer coordination, donation transparency, and administrative monitoring into one accessible digital platform.

---

# 🌟 Overview

Traditional stray animal rescue operations often rely on social media posts, messaging apps, and manual spreadsheets, leading to delayed responses, inconsistent records, and inefficient coordination.

PAWLSE modernizes these processes through:
- AI-assisted rescue reporting
- Structured adoption workflows
- Volunteer coordination tools
- Donation transparency monitoring
- Advanced administrative and Super Admin controls

The system is designed to improve operational efficiency, accountability, and community engagement in animal welfare initiatives.

# 📊 System Architecture

PAWLSE follows a **Three-Tier Architecture**.

## 1️⃣ Presentation Layer
Handles the user interface and role-based dashboards.

## 2️⃣ Application Layer
Processes business logic, AI workflows, rescue operations, and management systems.

## 3️⃣ Data Layer
Stores rescue reports, users, donations, adoption records, volunteers, and audit logs using MySQL.
